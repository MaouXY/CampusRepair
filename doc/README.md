# 校园智能报修服务平台项目前期文档

本目录用于沉淀《基于 Spring Boot 和 Vue 的校园智能报修与工单调度系统设计与实现》前期调研、分析与规划材料。

建议论文题目可二选一：

1. 《基于 Spring Boot 和 Vue 的校园智能报修与工单调度系统设计与实现》
2. 《基于大语言模型辅助分类的校园智能报修服务平台设计与实现》

如果答辩和论文希望突出工程实现，建议使用题目 1；如果希望突出 AI 特色，建议使用题目 2。

- [04_AI模块设计方案.md](04_AI模块设计方案.md)：AI 赋能点、调用流程、兜底策略、提示词与可观测性要求。
- [05_开发计划与风险分析.md](05_开发计划与风险分析.md)：里程碑、优先级、测试规划、风险与答辩防守点。

- [08_分阶段实现计划.md](08_分阶段实现计划.md)：从项目初始化到测试答辩的阶段化实施计划。
